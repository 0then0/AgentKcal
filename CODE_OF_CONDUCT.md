# Code of conduct

AgentKcal welcomes users and contributors with different experience levels and backgrounds. Discuss technical choices with evidence, explain assumptions and treat other participants respectfully.

## Expected behavior

- Give constructive feedback about code, documentation and ideas.
- Respect different levels of technical experience.
- Keep conversations focused on the issue or contribution.
- Protect other people's privacy, including usage metadata and agent conversations.

Harassment, discriminatory abuse, threats, sexualized content directed at others, and disclosure of another person's private information are not acceptable.

## Reporting and enforcement

Report concerns through a private repository contact channel where available. If no channel is available, request one in an issue without disclosing sensitive information publicly. Security vulnerabilities should follow the [security policy](SECURITY.md).

Maintainers may edit or remove content and restrict participation in response to violations. Enforcement considers the behavior, its impact and the context. Good-faith technical disagreement is welcome.

This policy applies to project issues, pull requests, reviews, discussions and other project interactions.
